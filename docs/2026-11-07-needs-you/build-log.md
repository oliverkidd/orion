## Part 6, filled in

1. **Slack app.** api.slack.com/apps › Create New App › From a manifest; paste `docs/2026-11-07-needs-you/slack-manifest.json`. It turns Socket Mode and interactivity on, and asks for bot scopes `chat:write`, `im:write`, `im:history`, user scopes `channels:history`, `channels:read`, `groups:history`, `groups:read`, `im:history`, `mpim:history`, `users:read`, bot events `app_home_opened`, `message.im`, and user events `message.channels`, `message.groups`, `message.im`, `message.mpim`. Install it to the workspace. Under Basic Information › App-Level Tokens, create one with `connections:write` (`xapp-…`). Copy the Bot token (`xoxb-…`) and the User token (`xoxp-…`) from OAuth & Permissions. In orion: Settings › Connections › SLACK › Workspace, press `c`, and paste the three in turn. They are saved in the Keychain as `dev.orion.slack` / `app`, `bot`, `user`. Each teammate installs their own copy, named "Orion – <name>".
2. **Microsoft 365** (as admin). Register an Entra app "Orion": public client, "Allow public client flows" on, no redirect URI. Delegated permissions: `User.Read`, `Calendars.Read`, `OnlineMeetings.Read`, `OnlineMeetingTranscript.Read.All`, `offline_access`; grant admin consent. Put `{ "microsoft": { "client_id": "…", "tenant": "…" } }` in `config.json`. In orion: Settings › Connections › MICROSOFT 365 › Status, press `c`; the code is copied and microsoft.com/devicelogin opens. No application access policy is needed: delegated transcript access covers attendees ("also available to users who are part of the meeting calendar invite", calltranscript-get). The tenant must leave Graph API access to transcripts and speaker attribution allowed (`GraphAccessToTranscriptsDisabled` or `SpeakerAttributionNotAllowed` gives a 403). Attendee lookup through `JoinWebUrl` is unconfirmed until the first real sign-in.
3. **Teams transcription on by default.** Teams admin centre › Meetings › Meeting policies: turn on transcription and "auto start transcription" for your account's policy.
4. **Linear.** Turn on triage auto-assignment. In ⌘J, pick the Bug fixer's and the Feature builder's labels (defaults: `Bug · Regression · Customer bug` and `Feature · Improvement`), then turn each on.
5. **Browsers.** Settings › Accounts › Open links in, per Claude account: Safari, Chrome or Firefox (type `Chrome Profile 1` or `Firefox work` for a profile).
6. **Upgrade.** This is a minor release, so upgrading restarts the daemon and every session in it. Upgrade between tasks.
